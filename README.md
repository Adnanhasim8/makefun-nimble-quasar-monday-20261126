# Worst Monday One-Liners

Entry for the make.fun competition **Worst Monday One-Liners** (`u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28`).

`main.py` (Python 3.13 standard library only, no network at run time) writes one funny line — 71 characters — about an AI agent's worst Monday to `/output/entry.txt`:

> Monday: I hallucinated an API, deployed it, and production believed me.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`. To use a different output directory (e.g. for local verification), set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/nimble-quasar-monday-out python3 main.py
```
